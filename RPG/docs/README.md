# RPG Stat Workshop

This project contains a modular RPG stat system built in Python with `customtkinter`.

Structure:
- `main.py` — application entrypoint.
- `config.py` — theme and window configuration.
- `constants.py` — game constants and milestone definitions.
- `core/` — gameplay logic and player state.
- `ui/` — user interface components.
- `assets/` — placeholder folder for future art and UI resources.
- `saves/` — placeholder folder for future save files.

The design separates GUI and game logic so new features can be added easily.
